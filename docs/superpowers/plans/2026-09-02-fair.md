# Naman's World Fair (v4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the world as a flat fenced fairground: Wordle ticket at the gate, a front-facing Career Coaster that rides the résumé timeline, midway stalls for the five games (with reveal options and Word Forge persistence), Hook-a-Duck, and a guestbook — replacing the island, its interiors and the tower.

**Architecture:** The terrain painter, bake pipeline, mini-game host, GameState/facet model, story spine, HUD/journal/map and the five game reducers stay. `Blueprint` gains `attractions` (outdoor interactables with footprints and doors) and loses rooms; the generator becomes a designed fair layout on the same `Grid`. The coaster is data (`data/coaster.ts`: a drawn profile polyline + content-derived stops) + a pure sampler (`systems/ridepath.ts`) + a thin Phaser runner (`systems/Coaster.ts`). Deletions (interiors, boat, tower, unused buildings) happen in Wave 2 when their consumers are rewritten.

**Tech Stack:** TypeScript, Phaser 3, Vite, vitest + happy-dom, procedural pixel art.

**Spec:** `docs/superpowers/specs/2026-09-02-fair-design.md` (binding). v3 spec `docs/superpowers/specs/2026-09-02-story-isle-design.md` §5–§6 still govern cards, locks and the games.

## Global Constraints

- **Never commit or push.** v3 checkpoint is `a94c31f` on `v3/story-isle`; v4 work stays uncommitted on the same branch until the user says otherwise.
- Résumé facts only from `src/data/content.ts`; coaster stop copy must be derived from content (test-enforced); dialogue lines carry **no digits**, no emoji, no unapproved skills; the stealth product stays unnamed.
- `ui/*` never imports `core/keys`; `core/`, `world/`, `src/games/*`, `src/data/*` never import Phaser or DOM (`systems/ridepath.ts` is pure too).
- Save field names stay (`packets`, `chests`, `fish`, `discoveries`) — only labels change; schema key becomes `nw2.save.v4`.
- Canvas/ride motion: fixed-step or tween-driven, interpolated, DPR-aware; reduced motion honoured.
- File ownership is strict per task; one CSS file per new UI module under `src/styles/`.
- Gates per task: the task's suites + `npx tsc --noEmit` (for owned files while the wave is in flight); full `npm test` at wave end; `npm run build` at the end.
- Windows shell: helper scripts go in `scratch/*.cjs` written with the Write tool. Browser checks run against `npm run build && npx vite preview --port 4173` (the dev server reloads under concurrent edits).
